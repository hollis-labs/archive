## Description

Add issue and PR templates to guide contributors toward useful reports
and well-structured pull requests.

## Files

**`.github/ISSUE_TEMPLATE/bug_report.md`**
- Summary / what happened / what was expected
- Steps to reproduce
- OS, Go version, binary version
- Relevant logs

**`.github/ISSUE_TEMPLATE/feature_request.md`**
- What you want + why
- Alternatives considered

**`.github/PULL_REQUEST_TEMPLATE.md`**
- Summary of change
- Type (bug fix / feature / docs / refactor)
- Tests added? (yes/no)
- Docs updated? (yes/no)

## Acceptance
- [ ] Bug report template present and usable
- [ ] Feature request template present
- [ ] PR template present
- [ ] All templates use the new project name
