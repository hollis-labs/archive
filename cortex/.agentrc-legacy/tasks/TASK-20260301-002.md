## Description

Produce a written decision document listing exactly which files and directories
go into the new public repo vs. stay in this dev workspace. This gates the
actual export (TASK-20260301-005).

## Proposed scope (confirm or adjust)

**Include in public repo:**
- `cmd/contextd/` — binary entrypoint
- `internal/` — all service packages (contextapi, contextcli, contextpolicy,
  contextstore, mcpadapter, taskscli)
- `tests/` — integration tests
- `docs/QUICKSTART.md`
- `docs/AGENT-SETUP.md`
- `docs/CONTEXT-FOR-PROJECTS.md`
- `docs/SPECS/` — API.md, CLI.md, MCP.md, NAMESPACES.md, PROMOTION.md,
  STORAGE.md, VIEWS.md, MVP.md (review each for user relevance)
- `examples/` — directory exists; review contents
- `Makefile`
- `go.mod`, `go.sum`
- `LICENSE` (new — from TASK-20260301-003)
- `README.md` (new — from TASK-20260301-006)
- `.github/` (new — CI, issue templates)

**Exclude from public repo (stays in dev workspace only):**
- `.volon/`, `volon.yaml`, `CLAUDE.md` — Volon system files
- `SPEC-TASKS/` — evaluation spec / internal planning
- `artifacts/`, `outputs/` — internal planning artifacts
- `plugins/`, `workflows/`, `scripts/` — Volon tooling
- `docs/01_*.md` through `docs/15_*.md` — Volon internal docs
- `docs/ideation-naming-001.md`, `docs/volon-*.md`, `docs/pcc_layers.md`,
  `docs/AGENTS.md`, `docs/tasks.md`, `docs/queue_task_runner.md` — internal
- `docs/FORGE_ALIGNMENT.md`, `docs/CONTRACT_FIXTURES.md` — internal
- `user-docs-mini-site/` — website source lives in a separate repo or
  subdirectory; not part of the service binary repo
- `VOLON_AGENT_ENVELOPE_SPEC.md`, `VOLON_INVARIANTS.md`,
  `volon_v0.4_execution_brief.md` — root Volon files
- `data/` — local runtime data
- `contextd` — compiled binary artifact
