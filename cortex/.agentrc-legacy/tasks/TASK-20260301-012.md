## Description

Add a GitHub Actions workflow to the public repo that runs on every push
and pull request. This is the status check required by branch protection.

## Workflow: `.github/workflows/ci.yml`

Triggers: `push` to `main`, `pull_request` to `main`

Jobs:
1. **test** — `go test -race ./...`
   - Matrix: Go 1.23 and 1.24 (or whatever the min supported version is)
   - OS: ubuntu-latest (SQLite builds cleanly on Linux; add macos if desired)
2. **build** — `go build ./cmd/...`
   - Confirm the binary builds successfully

Optional (B priority, add if not time-consuming):
- `golangci-lint` run (add `.golangci.yml` config)
- `go vet ./...`

## Acceptance
- [ ] `.github/workflows/ci.yml` exists in public repo
- [ ] Workflow runs on push and PR to main
- [ ] `go test -race ./...` job passes on clean checkout
- [ ] `go build ./cmd/...` job passes
- [ ] Workflow badge added to README.md

## Notes

- CGO is required for SQLite (`modernc.org/sqlite` is pure Go — verify which
  driver is in use and set CGO_ENABLED accordingly).
- Check `go.mod` for the minimum Go version before setting matrix versions.
