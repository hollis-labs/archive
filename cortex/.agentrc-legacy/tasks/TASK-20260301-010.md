## v0.1.0 content

Key features to call out:
- SQLite-backed revision store with namespace + key + actor model
- 14 MCP tools for full agent workflow (read, write, promote, broker, namespace, audit)
- CLI (`contextd context ...`) for all store operations
- HTTP API for direct integration
- Capability token system with scoped namespace access
- Tiered namespace model (app/* vs user/*)
- Promotion lifecycle (request → approve → apply)
- Context packet with budget-bounded manifest
- Broker plan with intent-based namespace generation
