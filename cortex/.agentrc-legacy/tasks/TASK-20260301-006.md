Write the root `README.md` for the public repo. This is the first thing anyone
sees. The current README in the dev workspace describes Volon, not this service.

## Structure

1. **One-line description** — what it is
2. **30-second pitch** — 2–3 sentences: what problem it solves, who it's for
3. **Install** (3 commands: clone/go install, run, create token)
4. **First write + first read** (copy-paste example)
5. **MCP setup** (the 3-line `.mcp.json` block)
6. **What's inside** — brief feature list (14 MCP tools, CLI, HTTP API, namespaces, promotion)
7. **Docs links** — QUICKSTART, AGENT-SETUP, CONTEXT-FOR-PROJECTS, API ref
8. **License badge + license line**
