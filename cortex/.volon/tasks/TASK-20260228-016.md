## Description

This task wires the capability token fields (from TASK-20260228-015) into request authorization. Currently `authorizeMutatingRequest` validates the token exists, is not expired, and is not revoked — but does not check scopes or namespace_globs. After this task, a token without the required scope or namespace access will be rejected with a structured error.

**Pre-condition**: TASK-20260228-015 must be complete (token schema has scopes and namespace_globs).

**Update `authorizeMutatingRequest` to**:

1. **Attach token claims to request context**: After validating the token, parse `Scopes` and `NamespaceGlobs` and attach them to the Go request context (`context.WithValue`).

2. **Scope check**: Each handler that requires a specific scope should call `RequireScope(ctx, "write")` (or equivalent) before proceeding. Return `403 Forbidden` with:
   ```json
   { "error": "insufficient_scope", "required": "write", "token_client": "app:myapp" }
   ```

3. **Namespace glob check**: Before any write/promote, check that the target namespace matches at least one of the token's `namespace_globs`. Use the existing glob matching logic. Return `403 Forbidden` with:
   ```json
   { "error": "namespace_not_permitted", "namespace": "user/memory/foo", "token_globs": ["app/myapp/*"] }
   ```

**Enforcement points** (add scope + namespace check to each):
- `AppendRecord` handler: requires `write` scope + namespace match
- `promote.request` handler: requires `promote.request` scope + namespace match
- `promote.approve` handler: requires `promote.approve` scope (user-only)
- `promote.apply` handler: requires `promote.apply` scope
- `/v1/maintenance/*` handlers: requires `repair` scope
- `/v1/namespace/register`: requires `namespace.register` scope

**Backward compatibility**: Tokens with `namespace_globs: ["*"]` and full scopes (the migration default from TASK-20260228-015) must pass all checks. Do not break existing authenticated requests.

## Acceptance

- [ ] A token with `scopes: ["packet"]` cannot call `AppendRecord` — returns `403 insufficient_scope`.
- [ ] A token with `namespace_globs: ["app/myapp/*"]` cannot write to `user/memory/foo` — returns `403 namespace_not_permitted`.
- [ ] Tokens with `namespace_globs: ["*"]` can write to any namespace (full-access default).
- [ ] All enforcement happens before the policy engine — token check is the first gate, policy engine is the second.
- [ ] Error responses include structured JSON (not plain text messages).
- [ ] Tests: one test per scope check, one test per namespace glob check (allowed + blocked cases).
