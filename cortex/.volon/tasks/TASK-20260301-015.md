## Description

Register the domain chosen in TASK-20260301-001 and deploy the mini-site.

## Steps

1. **Register domain**
   - Registrar: Namecheap, Cloudflare, or similar
   - Enable auto-renew
   - Set up DNS management (Cloudflare DNS recommended for free CDN/HTTPS)

2. **Decide deploy target**
   - **GitHub Pages** — simplest; free; custom domain supported
     - Create `<name>-site` repo (or use `gh-pages` branch in main repo)
     - Add `CNAME` file with domain
     - Enable Pages in repo settings → custom domain
   - **Netlify** — slightly more setup; adds form handling, deploy previews
     - `netlify.toml` in site root
     - Connect GitHub repo, set publish directory

3. **HTTPS**
   - Both GitHub Pages and Netlify provision Let's Encrypt automatically
     once DNS propagates

4. **DNS**
   - Point domain apex (or www) to the deploy target
   - Verify HTTPS works before publicizing

## Acceptance
- [ ] Domain registered
- [ ] DNS configured and propagated
- [ ] Site live at `https://<domain>/`
- [ ] HTTPS working (no certificate errors)
- [ ] GitHub repo description updated with live URL
- [ ] QUICKSTART.md and README.md in public repo link to the site

## Notes

- DNS propagation can take 0–48 hours. Start this early.
- For GitHub Pages with a custom domain: set the domain in Pages settings
  *and* add a `CNAME` file to the repo root. Both are required.
