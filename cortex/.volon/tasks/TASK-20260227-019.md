## Description

Implement the MCP adapter for the `phase-1-read-view` capability set. This is a thin
stdio transport layer in `internal/mcpadapter/` that maps MCP tool calls to existing
API/CLI contracts. No new business logic — the adapter delegates to the same handlers
as the HTTP API.

**Phase-1 tools (read only, default-enabled)**:
- `context_head` — maps to `GET /v1/context/head`
- `context_history` — maps to `GET /v1/context/history`
- `views_evaluate` — maps to `POST /v1/views/evaluate`
- `namespaces_get` — maps to `GET /v1/namespaces/get` (explicitly-enabled)

**Transport**: stdio (standard for local-first MCP usage per MCP spec threat model).

**Package location**: `internal/mcpadapter/`

**Entrypoint options** (pick one):
- `cmd/contextd` gains a `--mcp` flag that starts the adapter instead of the HTTP server
- OR create `cmd/contextmcp` as a separate binary

**Pre-condition**: Phase 0 must be complete (spec accurate, checksum fixed).
