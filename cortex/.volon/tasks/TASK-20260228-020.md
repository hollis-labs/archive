## Agent Context

**What to build**: The scaffolding that makes subsequent tool tasks possible. This task
does NOT implement any tools — it builds the server, wires the store, and registers
stubs. Subsequent tasks fill in the handlers.

**Library**: `mark3labs/mcp-go` — the standard Go MCP server library. Add it via
`go get github.com/mark3labs/mcp-go`.

**Architecture**:
- New package: `internal/mcpadapter/`
- New files: `adapter.go` (Adapter struct, Run method), `tools.go` (tool registration)
- Entry flag: `--mcp` on `contextd` binary
- Auth flag: `--mcp-token <token>` — a capability token with appropriate scopes
- DB flag: reuse `--db` flag already on contextd

**How --mcp works**:
```
contextd --mcp --db ~/.context/context.db --mcp-token tok_abc123
```
When `--mcp` is set, skip the HTTP server entirely and run the MCP adapter.
The adapter opens the Store, registers tools, starts the mcp-go stdio server.

**Adapter struct**:
```go
type Adapter struct {
    Store    *contextstore.Store
    Token    string  // capability token (may be empty — read tools work without it)
    Enabled  []string // enabled tool names (default: all)
}

func (a *Adapter) Run(ctx context.Context) error
```

**Tool stubs**: Register all 6 tools with handlers that return a placeholder response.
This lets us verify the protocol works before filling in real logic.

Tools to register (stubs):
- `context_head` — read a record head
- `context_history` — read record history
- `context_view` — evaluate a view selector
- `context_packet` — get a budget-bounded context packet
- `context_write` — write a record (mutating)
- `context_promote_request` — request a promotion (mutating)

**mcp-go server pattern**:
```go
s := server.NewMCPServer("context-memory-service", "0.1.0")
s.AddTool(mcp.NewTool("context_head", ...), a.handleHead)
// ...
if err := server.ServeStdio(s); err != nil { ... }
```

**cmd/contextd/main.go changes**:
- Add `mcpMode bool` and `mcpToken string` flags
- When `mcpMode`: open Store, create Adapter, call adapter.Run(ctx), exit on return
