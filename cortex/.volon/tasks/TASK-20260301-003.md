## Description

Decide on the open source license for the public repo and add a `LICENSE` file
to the export. This is a human decision; the agent adds the file once decided.

## Options

| License | Best for | Key terms |
|---|---|---|
| **MIT** | Maximum permissiveness; widest adoption | Anyone can use, modify, distribute; just keep copyright notice |
| **Apache 2.0** | Permissive + patent grant | Like MIT but explicitly grants patent rights; preferred by enterprises |
| **AGPL-3.0** | Copyleft; requires open source if you run it as a service | Protects against SaaS forks without contribution |

**Recommendation:** MIT or Apache 2.0 for broadest adoption. AGPL if you want
to prevent someone from wrapping this in a closed SaaS without giving back.
