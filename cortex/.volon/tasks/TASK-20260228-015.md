## Agent Context

**What already exists** (read these before implementing):
- `internal/contextapi/server.go` — `authorizeMutatingRequest()` (line ~171): validates token exists/not-expired/not-revoked. This task extends the token schema; TASK-20260228-016 wires the new fields into `authorizeMutatingRequest`.
- `internal/contextstore/store.go` — `ValidateAuthToken`, `CreateAuthToken`, `ListAuthTokens`, `RevokeAuthToken`. The auth_tokens schema is defined here in the `CREATE TABLE` statement. Find it and extend it.
- `internal/contextcli/cli.go` — There is currently no `context token` subcommand. This task adds it.

**What this task does**: schema + model changes ONLY. It does NOT wire the new scopes/namespace_globs into handler enforcement — that is TASK-20260228-016.

**Backward compatibility**: Existing tokens (which have empty scopes) must not break. Use a migration default of full access (all scopes, `namespace_globs: ["*"]`) for any token where scopes is empty.

**Security note**: Token values are hashed in the DB (SHA-256). When creating a new token, generate a random token value, return it to the caller once and only once, store the hash. Never return the token value again.

## What to Build

### 1. Schema extension (internal/contextstore/store.go)

Add three columns to `auth_tokens`:

```sql
ALTER TABLE auth_tokens ADD COLUMN client_id TEXT NOT NULL DEFAULT '';
ALTER TABLE auth_tokens ADD COLUMN scopes TEXT NOT NULL DEFAULT '["write","promote.request","promote.approve","promote.apply","packet","repair","namespace.register"]';
ALTER TABLE auth_tokens ADD COLUMN namespace_globs TEXT NOT NULL DEFAULT '["*"]';
```

Handle the migration: on startup, if any existing token row has `scopes = '[]'` or `namespace_globs = '[]'`, update it to the full-access defaults.

**Valid scope values** (enum, store as JSON string array):
- `write` — AppendRecord on permitted namespaces
- `promote.request` — create promotion requests
- `promote.approve` — approve promotion requests (user-only)
- `promote.apply` — apply approved promotions
- `packet` — call /v1/context/packet
- `repair` — call maintenance/repair endpoints
- `namespace.register` — register new namespaces

Update `AuthToken` Go struct:
```go
type AuthToken struct {
    ID              string    `json:"id"`
    Name            string    `json:"name"`
    ClientID        string    `json:"client_id"`
    Scopes          []string  `json:"scopes"`
    NamespaceGlobs  []string  `json:"namespace_globs"`
    ExpiresAt       time.Time `json:"expires_at"`
    Revoked         bool      `json:"revoked"`
    CreatedAt       time.Time `json:"created_at"`
}
```

Update `CreateAuthToken` to accept `ClientID`, `Scopes`, `NamespaceGlobs`.

Update `ListAuthTokens` and token read path to return all new fields.


### 3. CLI commands (internal/contextcli/)

```bash
# Create a scoped token for an app agent
context token create \
  --name "claude-agent" \
  --client-id "app:claude" \
  --scopes write,packet,promote.request \
  --namespaces "app/claude/*" \
  --expires "2027-01-01"

# Create a user token (full access, for operators)
context token create --name "my-operator-token" --client-id "user"

# List all tokens (never shows raw values)
context token list [--show-revoked]

# Show a specific token's details
context token show <token-id>

# Revoke a token
context token revoke <token-id>
```

Output for `token create`:
```
Token created. Copy this value now — it will not be shown again.

  Token:      cms_abc123def456...  ← raw value, shown ONCE
  ID:         tok-abc
  Name:       claude-agent
  Client:     app:claude
  Scopes:     write, packet, promote.request
  Namespaces: app/claude/*
  Expires:    2027-01-01
```

Output for `token list`:
```
ID        NAME             CLIENT        SCOPES                    NAMESPACES     EXPIRES     STATUS
tok-abc   claude-agent     app:claude    write,packet,prm.req      app/claude/*   2027-01-01  active
tok-xyz   operator-token   user          (all)                     *              never       active
tok-old   legacy-agent     (none)        (legacy-full-access)      *              2026-03-01  active
```

Output for `token revoke`:
```
Token tok-abc revoked. Requests using this token will be rejected immediately.
```

Add `runToken` dispatch in `cli.go`. Subcommands: create, list, show, revoke.
