## Description

Extend the MCP adapter with write and promote tool surfaces. These are explicitly-enabled
(not default-on) and require capability token scopes from Phase 4. All operations delegate
to existing API handlers — no parallel business logic in the adapter.

**Phase-2 tools (explicitly-enabled)**:
- `context_packet` — maps to `POST /v1/context/packet`
  - This is the primary agent continuity surface: budget-bounded, manifest-returning

**Phase-3 tools (explicitly-enabled, mutating)**:
- `context_write` — maps to `POST /v1/context/write`
- `context_promote_request` — maps to `POST /v1/context/promote/request`
- `context_promote_approve` — maps to `POST /v1/context/promote/approve`

**Pre-conditions** (all must be complete before starting this task):
- TASK-20260227-019 (MCP phase-1 adapter)
- Phase 2 complete: `POST /v1/context/packet` implemented (TASK-20260227-010)
- Phase 4 complete: capability tokens enforced (TASK-20260227-016)
- Phase 3 complete: gated promotion implemented (TASK-20260227-014)

**Enablement rule**: Write/promote tools are opt-in. The adapter must require explicit
configuration to enable mutating tools; they must not be default-enabled.
