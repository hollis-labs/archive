## Description

The namespace policy system exists (`namespace_policies` table and `Server.reloadPolicies()`) but the schema only enforces basic ownership. This task extends the policy schema with deterministic enforcement fields for the tier model defined in TASK-20260228-007.

**Pre-condition**: TASK-20260228-007 must be complete. The policy schema extension must match the tier model spec.

**Fields to add to the policy schema**:

```json
{
  "tier": "memory|cache|pins|draft|session",
  "retention": "duration string, e.g. 72h — for cache/session tiers only",
  "max_revisions": "integer — max revisions per (namespace, key)",
  "max_bytes_per_key": "integer — max payload bytes per key",
  "allowed_ops": ["write", "promote.request", "promote.apply", "repair", "namespace.register"],
  "required_schema_keys": ["list of required metadata keys for memory tier records"],
  "redaction": {
    "allowed": "bool",
    "tombstone_on_delete": "bool"
  }
}
```

**Enforcement points to implement**:
- On write (`AppendRecord`): check `allowed_ops` contains `write`; check `max_bytes_per_key`; check `required_schema_keys` present in record metadata (memory tier only).
- On `promote.request`: check `allowed_ops` contains `promote.request`.
- On `promote.apply`: check `allowed_ops` contains `promote.apply`.
- `retention` and `max_revisions` are enforced by the maintenance job (TASK-20260228-009), not at write time.

**What this task does NOT implement**: the actual retention trimming/compaction (that's TASK-20260228-009). This task adds the schema fields and enforces them at write/promote time.

## Acceptance

- [ ] `AppendRecord` enforces `allowed_ops: write`, `max_bytes_per_key`, and `required_schema_keys` before persisting.
- [ ] `CanPromote` (or equivalent) enforces `allowed_ops: promote.request/apply` before proceeding.
- [ ] Policy enforcement returns structured errors: `{error: "policy_violation", field: "allowed_ops", detail: "write not permitted in namespace user/cache/foo"}`.
- [ ] Existing policies with missing new fields default safely (empty `allowed_ops` = all ops permitted for backward compat, or fail-open with a warning — document the chosen default).
- [ ] Tests cover: blocked write (op not in allowed_ops), blocked promote, max_bytes exceeded, missing required key.
