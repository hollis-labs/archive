## Agent Context

**Pre-condition**: TASK-20260228-020 must be complete (adapter foundation + tool stubs).

**Auth posture**: Read tools are open (`mvp-open-read`). No token required. They never
mutate state, so no capability check is needed.

**What to implement** (replace the 3 read stubs from TASK-020):

### context_head

Maps to `store.Head(ctx, namespace, key)`.

Tool input schema:
```json
{
  "namespace": { "type": "string", "description": "Namespace path, e.g. user/memory/task-001" },
  "key": { "type": "string", "description": "Record key" }
}
```

Response (success):
```json
{
  "record_id": "rec_...",
  "namespace": "user/memory/task-001",
  "key": "state",
  "payload": { ... },
  "revision": 3,
  "created_at": "2026-02-27T...",
  "actor": "app:test",
  "checksum": "sha256:..."
}
```

Response (not found): return a structured error response with `code: "not_found"` rather
than an MCP protocol error. Agents can check for this and branch accordingly.

### context_history

Maps to `store.History(ctx, namespace, key, limit)`.

Tool input schema:
```json
{
  "namespace": { "type": "string" },
  "key": { "type": "string" },
  "limit": { "type": "integer", "description": "Max records to return (default 20, max 100)" }
}
```

Response: array of records, newest first (matches API determinism).

### context_view

Maps to `store.Select(ctx, selector)`. Allows arbitrary view selector evaluation.

Tool input schema:
```json
{
  "selector": {
    "type": "object",
    "description": "View selector (namespaces, revision_scope, order, limit, tags)"
  }
}
```

Response:
```json
{
  "items": [ ... ],
  "count": 3,
  "truncated": false
}
```

**Error handling pattern** (apply consistently to all read tools):
- Store error that is "not found" type → return `{"code":"not_found","message":"..."}`
- Validation error (missing required args) → return `{"code":"validation_error","message":"..."}`
- Unexpected error → return `{"code":"internal_error","message":"..."}` (do not surface raw Go errors)

All errors should be returned as the MCP tool call result content (not as MCP protocol
errors), so agent code can parse and handle them.
